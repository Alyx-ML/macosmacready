# MacReady Design Notes

## Visual Direction
MacReady uses a dark, glass-like macOS desktop shell with restrained color, high image presence, and compact reader-friendly panels.

## Layout
- The first story should feel editorial and intentional, with a wide visual lead and a structured text column.
- Supporting stories can use a denser card grid.
- Sidebar sections should remain predictable: Library first, categories second.
- Text blocks should align to clear internal edges and avoid floating in large empty areas.

## Typography
- Use the existing system-style UI type.
- Headlines should be bold and readable, but not oversized inside compact app panels.
- Metadata should sit close to the content it describes.

## Color
- Keep content text white or softly tinted white in dark mode.
- Avoid blue content text except for clear interactive system controls.
- Source badges should read as quiet glass labels, not bright links.

## Components
- News cards need clear source/date placement.
- The featured card should use a composed metadata row, headline, excerpt, and source identity.
- Hover states should not make news headlines bright blue.
